# Ансамбли

{class}`~flexpredict.EnsemblePredictor` объединяет predictor-подобные объекты, возвращающие
{class}`~flexpredict.PredictionResult`.

```python
ensemble = EnsemblePredictor(
    [predictor_a, predictor_b, predictor_c],
    aggregation="weighted_mean",
    aggregation_weights=[0.5, 0.3, 0.2],
    name="risk-ensemble",
)
```

## Стратегии

| Стратегия | Требование | Результат |
| --- | --- | --- |
| `mean` | числа | среднее; значение по умолчанию |
| `weighted_mean` | числа | взвешенное среднее |
| `median` | числа | медиана |
| `min`, `max` | числа | минимум или максимум |
| `voting` | одна метка | голосование |
| callable | произвольный | пользовательская агрегация |

## Веса

Веса относятся к моделям целиком, а не к параметрам нейросети. Можно передать sequence,
NumPy array или `.npy` файл. Веса должны быть конечными, неотрицательными, соответствовать
числу моделей и иметь положительную сумму. Они нормализуются и становятся read-only.

`.npy` загружается с `allow_pickle=False`. Если веса для `weighted_mean` не заданы, они
равные.

## Разные признаки и фреймворки

Каждый участник получает исходный request, самостоятельно выбирает признаки и выполняет
preprocessing. Поэтому модели могут использовать разные подмножества и порядок признаков,
а также разные фреймворки.

## Совместимость

Должны совпадать task, output kind, полная форма, `is_single` и классы. Для probabilities и
logits одинаковый набор классов может иметь разный порядок: столбцы будут переставлены по
первой модели.

`voting` работает только с одной меткой на объект. При равенстве голосов побеждает более
ранний участник.

## Своя агрегация

Callable получает форму `(n_predictors, n_samples, n_outputs)` и должен вернуть
`(n_samples, n_outputs)`. Совмещать callable с `aggregation_weights` нельзя.

Ошибка участника превращается в {class}`~flexpredict.EnsembleInferenceError` с его индексом
и именем, поэтому задавайте понятные `name`.
