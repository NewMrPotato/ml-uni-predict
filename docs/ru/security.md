# Безопасность

## Считайте модельные артефакты кодом

Python pickle, joblib и некоторые форматы фреймворков способны выполнить код при загрузке.
Используйте только файлы из доверенного build pipeline с проверенной целостностью.

FlexPredict уменьшает риск случайной ошибки, но не делает небезопасный формат безопасным:

- `.pt` и `.pth` не угадываются автоматически;
- state dict по умолчанию использует `weights_only=True`;
- полная PyTorch-модель требует `loader="torch_model"` и использует `weights_only=False`;
- `.npy` веса ансамбля загружаются с `allow_pickle=False`.

## Проверяйте вход

На внешней границе используйте {class}`~flexpredict.InputSchema`: она запрещает лишние поля,
проверяет обязательность и null, преобразует типы и запускает domain validators.

## Ограничивайте ресурсы

Библиотека проверяет форму и пустые пакеты, но не ограничивает размер request, batch, время
инференса или память. Такие лимиты должен задавать сервис вокруг неё.

Проверка результата защищает от NaN, Infinity, complex и случайных объектов, но не доказывает
точность, калибровку или справедливость модели.
