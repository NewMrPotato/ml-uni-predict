# Основные понятия

## Конвейер инференса

Каждый {class}`~flexpredict.Predictor` выполняет одинаковую последовательность:

1. определяет одиночный объект или пакет;
2. выбирает, упорядочивает и проверяет признаки;
3. применяет необязательную предобработку;
4. вызывает inference engine;
5. выбирает нужный выход модели;
6. приводит результат к `(n_samples, n_outputs)`;
7. проверяет семантику результата;
8. возвращает {class}`~flexpredict.PredictionResult`.

Благодаря этому каждая модель ансамбля может сохранить свою схему, preprocessing,
фреймворк и устройство, но приложение получает общий контракт.

## `features` или строгая схема

`features=[...]` создаёт схему выбора с `dtype=None` и `extra_fields="ignore"`. Она подходит,
когда важны наличие и порядок признаков.

Явная {class}`~flexpredict.InputSchema` по умолчанию преобразует типы и запрещает лишние
поля. Она подходит для внешних запросов и раннего обнаружения ошибок. Одновременно передать
`features` и `schema` нельзя.

## Задача и тип выхода

FlexPredict читает современные sklearn tags, затем `_estimator_type` и `classes_`, не делая
scikit-learn обязательной зависимостью. Для нейросетей и своих моделей задавайте `task`, если
его нельзя определить автоматически.

| Задача | `output_kind` | Смысл |
| --- | --- | --- |
| `regression` | `values` | конечные вещественные прогнозы |
| `classification` | `labels` | строки, bool или конечные числа |
| `classification` | `probabilities` | числа от 0 до 1 |
| `classification` | `logits` | ненормализованные оценки классов |
| `unknown` | `values` | общий числовой выход |

FlexPredict проверяет диапазон вероятностей, но не требует, чтобы сумма строки была равна
единице. Нормализация и калибровка остаются ответственностью модели.

## Нормализация формы

| Выход модели | Интерпретация |
| --- | --- |
| скаляр | одно значение для одного объекта |
| 1D длиной с пакет | одно значение на объект |
| 1D при одном объекте | несколько выходов одного объекта |
| 2D | готовый `(n_samples, n_outputs)` |

Большая размерность и несовпадающее число объектов отклоняются.

## Predictor и ансамбль

Predictor отвечает за одну цепочку от входа до результата. EnsemblePredictor вызывает
несколько таких цепочек, проверяет совместимость результатов, при необходимости выравнивает
столбцы классов и только после этого выполняет агрегацию.
